# Student Management System

A console-based Student Management System developed using **Java, JDBC, and MySQL** to manage student records efficiently.

## Features
- Add Student
- View Student Records
- Update Student Information
- Delete Student Records (CRUD Operations)

## Technologies Used
- Java
- JDBC
- MySQL
- OOP Concepts

## Database
Database Name:
student_management_system

Table Name:
students

## Project Structure
- Main.java → Main menu and user interaction
- Student.java → Student model class
- StudentDAO.java → CRUD operations
- DBConnection.java → Database connection

## How to Run
1. Install Java JDK
2. Install MySQL Workbench
3. Create the database and students table
4. Add MySQL JDBC connector
5. Run Main.java
